# Research Gap Rubric

## Valid Gap Pattern

Use this sentence shape:

```text
已有研究较多关注 A，但较少解释 B；因此可以在 C 场景中，用 D 方法，考察 E 机制。
```

## Gap Types

1. Object gap: same issue, under-studied actors or groups.
2. Context gap: same issue, under-studied platform, region, institution, historical setting, or usage scene.
3. Mechanism gap: phenomenon observed, mechanism under-explained.
4. Method gap: qualitative-heavy field needs experiments/computation, or quantitative-heavy field needs process tracing/fieldwork.
5. Theory gap: imported theory does not explain local empirical features.
6. Failure gap: existing work studies success/linkage/adoption, but ignores failure/refusal/breakdown.
7. Temporal gap: cross-sectional work misses process, stages, or long-term effects.
8. Comparative gap: single-case work lacks cross-platform, cross-region, or cross-group comparison.

## Reject Weak Gaps

Reject if the gap is only:

- "few people studied this"
- "the topic is important"
- "technology is developing fast"
- "existing research is insufficient" without specifying what is insufficient
- a trendy noun phrase without object, scene, mechanism, and method

## Topic Viability Test

A topic is viable only if it has:

- concrete object
- concrete empirical scene
- accessible data
- explainable mechanism
- 2-3 research questions
- theory or concept that does analytical work
- feasible method for the user's degree level
- first-week validation task
